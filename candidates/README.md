# Candidate UIs

This directory holds alternative website implementations generated by different models or serving configurations, so they can be compared side-by-side.

## Structure

Each subdirectory is a self-contained candidate website:

| Folder | Purpose |
|---|---|
| `model-fable/` | Candidate from Fable model |
| `model-a/` | Candidate from model A |
| `model-b/` | Candidate from model B |
| `model-c/` | Candidate from model C |
| `config-variant-1/` | Same model, different serving config (e.g. temperature, top-p) |
| `config-variant-2/ | Same model, different serving config |

## Adding a New Candidate

1. Create a new folder: `mkdir candidates/my-candidate`
2. Drop the generated website files into it (should include at least `index.html`)
3. Test locally: `python3 -m http.server 8000` from inside the candidate folder
4. Commit and push

## Comparing

To compare candidates side by side, serve each on a different port:

```bash
cd candidates/model-a && python3 -m http.server 8001 &
cd candidates/model-b && python3 -m http.server 8002 &
cd candidates/model-c && python3 -m http.server 8003 &
```

Then open each in a browser tab.
